Social Video Automation

Social Video Automation is a private content automation tool used to create, manage, upload, and publish short-form video content to authorized YouTube and TikTok accounts.

Purpose of the application

The application uses official authorization flows from Google/YouTube and TikTok so the account owner can grant access before any publishing or account operation occurs.

YouTube Integration

The application uses Google OAuth 2.0 to access an authorized YouTube account for operations such as uploading, scheduling, and managing video content requested by the account owner.

TikTok Integration

The application uses TikTok Login Kit and the TikTok Content Posting API to publish short-form video content to an authorized TikTok account. TikTok access is used only after the account owner explicitly authorizes the application.

Authorization and Security

The application does not request or store Google or TikTok account passwords. Access is performed using OAuth access tokens and related authorization credentials.
